# o-848 Skin Mesh Transfer

**part of o-848 Tools** — by OhashiYa

[English version](README.md)

スキン付きメッシュを、別の Maya シーンへ移植するツールです。
両方のシーンで同じ骨を使っていれば、メッシュ・スキンウェイト・マテリアルをワンクリックで移せます。

## マテリアルが増えない

普通に読み込むと、移植先のシーンに既にあるマテリアルまで `skin_mat1` のような複製として持ち込まれます。
このツールは、まず移植先のシーンを調べます。同じ名前のマテリアルがあれば、読み込んだメッシュを**既存のマテリアル**に面単位で割り当て直し、持ち込んだ複製は削除します。

- シーンが散らからない：マテリアルやシェーディンググループが重複しません。
- 移植先で調整済みのマテリアルがそのまま使えます。
- 複数のマテリアルを使うメッシュにも対応しています。面ごとの割り当ても保たれます。

これは既定の動作です。読み込んだマテリアルに接尾辞を付けて残すこともできます。

## 主な機能

- 同じ名前の既存マテリアルに割り当て直します（上記）。
- 複数のメッシュをまとめて移植できます。メッシュを選ぶか、グループを選ぶだけで中のスキン付きメッシュを自動で拾い、グループごと移します。
- メッシュ、スキン、骨、マテリアルだけを書き出します。リグのコントローラは含みません。
- 移植先のシーンにある同名の骨にバインドします。
- スキンウェイトを頂点単位で正確にコピーします。
- 移植先に無い骨があれば、処理を止めて骨の名前を一覧で表示します。
- 名前が競合したときは、読み込んだ側（`_imp`）と既存の側（`_old`）のどちらを改名するか選べます。
- 移植のあと、読み込んだ一時ノード（骨、元のメッシュ、使わなかったマテリアル）をすべて削除します。

## インストール

### ドラッグ＆ドロップ（おすすめ）

1. [最新のリリース](https://github.com/o-848/skin-mesh-transfer/releases/latest)を開き、**Assets** にある `o848_SkinMeshTransfer_vX.X.X.zip` をダウンロードします。
   - zip は丸ごと必要です。`install.mel` は同じフォルダにあるほかのファイルを使います。
2. ダウンロードしたファイルを解凍します。
3. `install.mel` を Maya のビューポートにドラッグ＆ドロップします。
4. シェルフの **o848** タブにボタンが追加されます。

ツールは `Documents/maya/scripts` にコピーされるので、同じ PC のどのバージョンの Maya でも使えます。
インストーラは `Maya.env` や `userSetup.py` を書き換えません。

### 手動

1. `scripts/o848_skin_mesh_transfer.py` を `Documents/maya/scripts` にコピーします。
2. Maya を再起動し、スクリプトエディタ（Python タブ）で次を実行します。

```python
import o848_skin_mesh_transfer
o848_skin_mesh_transfer.show_ui()
```

## 使い方

1. **元のシーン**：スキン付きメッシュ（またはそのグループ）を選択して **Export Selected Meshes** を押します。
2. **移植先のシーン**：**Import and Transfer** を押します。

読み込みは Undo（Ctrl+Z）で戻せません。取り消したいときは、移植したメッシュを削除してください。

### 1. 書き出し（Export from the source scene）

| 項目 | 説明 |
|---|---|
| Save to: Temp folder | Maya の一時フォルダに保存します。書き出すたびに上書きされます。（既定） |
| Save to: Custom folder | 保存するフォルダとファイル名を自分で決めます。ファイルを残したいときや、他の人に渡すときに使います。 |

項目の下に、実際に保存される場所が表示されます。

### 2. 読み込み（Import into the target scene）

| 項目 | 説明 |
|---|---|
| Import from: Last export | 直前に書き出したファイル（1. で設定した場所）を読み込みます。（既定） |
| Import from: Another file | **Browse...** を押して、このツールで書き出した `.ma` ファイルを選びます。任意のフォルダに保存したファイルや、他の人からもらったファイルを読み込むときに使います。 |
| If a material exists: Use the existing one | 同じ名前のマテリアルがシーンにあれば、それを割り当てます。（既定） |
| If a material exists: Import a copy | 読み込んだマテリアルに接尾辞を付けて残します。 |
| Place meshes under: Matching parent | 元の親と同じ名前のノードがあれば、その下に入れます。無ければワールド直下に置きます。（既定）グループを書き出した場合は、グループの置き場所になります。 |
| Place meshes under: Selected node | **Import and Transfer** を押したときに選択しているノードの下に入れます。ノードを1つだけ選んでください。 |
| Place meshes under: World | ワールド直下に置きます。 |
| If a name exists: Rename imported | 同じ名前のノードがあれば、読み込んだ側に接尾辞を付けます。（既定） |
| If a name exists: Rename existing | 同じ名前のノードがあれば、既存の側に接尾辞を付け、読み込んだ側は元の名前のままにします。古いメッシュを新しい版に入れ替えたいときに使います。 |
| Imported suffix | 読み込んだ側に付ける接尾辞です。既定は `_imp` です。 |
| Existing suffix | 既存の側に付ける接尾辞です。既定は `_old` です。 |
| Keep the original bind pose | 元のバインドポーズをコピーします。移植先の骨がポーズを取っていても正しく付きます。移植先の骨のバインドポーズが違う場合はオフにしてください。 |

### 任意のフォルダに保存したファイルを読み込むには

1. **Import into the target scene** の欄で **Another file** を選びます。
2. **Browse...** を押して `.ma` ファイルを選びます。
3. **Import and Transfer** を押します。

## 注意点と制限

- グループを書き出した場合は、移植先にグループも作り直します。同じ場所に同じ名前のグループが既にあれば、新しく作らずにそのグループの中へ入れます。
- 「Rename existing」でも、骨・骨を含むグループ・ロックされたノード・リファレンスのノードは改名しません。その場合は読み込んだ側を改名し、結果に表示します。
- 「Rename existing」でも、マテリアルを複製として読み込む場合は読み込んだ側に接尾辞を付けます（既存のマテリアルを使っている他のメッシュに影響させないため）。

- 骨は名前で照合します。同じ名前の骨が複数あるとエラーになります。
- 移植先にだけある骨（追加の揺れ骨など）は、スキンのインフルエンスに追加されません。
- スキンより前のデフォーマ（ブレンドシェイプなど）は、メッシュの形に焼き込まれます。
- 書き出す前に、モデリングのヒストリを削除しておいてください。
