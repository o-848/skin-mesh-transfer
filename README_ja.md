# o-848 Skin Mesh Transfer

**part of o-848 Tools** — by OhashiYa

[English version](README.md)

スキン付きメッシュを、別の Maya シーンへ移植するツールです。
両方のシーンで同じ骨を使っていれば、メッシュ・スキンウェイト・マテリアルをワンクリックで移せます。

## マテリアルが増えない

普通に読み込むと、移植先のシーンに既にあるマテリアルまで `skin_mat1` のような複製として持ち込まれます。
このツールは、まず移植先のシーンを調べます。同じ名前のマテリアルがあれば、読み込んだメッシュを**既存のマテリアル**に面単位で割り当て直し、持ち込んだ複製は削除します。

- シーンが散らからない：マテリアルやシェーディンググループが重複しません。
- 移植先で調整済みのマテリアルがそのまま使えます。
- 複数のマテリアルを使うメッシュにも対応しています。面ごとの割り当ても保たれます。

これは既定の動作です。逆に、読み込んだマテリアルで既存のものを置き換えたり、両方残して見比べたりすることもできます。

## 主な機能

- 同じ名前の既存マテリアルに割り当て直します（上記）。
- 複数のメッシュをまとめて移植できます。メッシュを選ぶか、グループを選ぶだけで中のスキン付きメッシュを自動で拾い、グループごと移します。
- メッシュ、スキン、骨、マテリアルだけを書き出します。リグのコントローラは含みません。
- 移植先のシーンにある同名の骨にバインドします。
- スキンウェイトを頂点単位で正確にコピーします。
- 移植先に無い骨があれば、処理を止めて骨の名前を一覧で表示します。
- 名前が競合したときは、読み込んだ側（`_imp`）と既存の側（`_old`）のどちらを改名するか選べます。
- 移植のあと、読み込んだ一時ノード（骨、元のメッシュ、使わなかったマテリアル）をすべて削除します。

## インストール

### ドラッグ＆ドロップ（おすすめ）

1. [最新のリリース](https://github.com/o-848/skin-mesh-transfer/releases/latest)を開き、**Assets** にある `o848_SkinMeshTransfer_vX.X.X.zip` をダウンロードします。
   - zip は丸ごと必要です。`install.mel` は同じフォルダにあるほかのファイルを使います。
2. ダウンロードしたファイルを解凍します。
3. `install.mel` を Maya のビューポートにドラッグ＆ドロップします。
4. シェルフの **o848** タブにボタンが追加されます。

ツールは `Documents/maya/scripts` にコピーされるので、同じ PC のどのバージョンの Maya でも使えます。
インストーラは `Maya.env` や `userSetup.py` を書き換えません。

### 手動

1. `scripts/o848_skin_mesh_transfer.py` を `Documents/maya/scripts` にコピーします。
2. Maya を再起動し、スクリプトエディタ（Python タブ）で次を実行します。

```python
import o848_skin_mesh_transfer
o848_skin_mesh_transfer.show_ui()
```

## 使い方

1. **元のシーン**：スキン付きメッシュ（またはそのグループ）を選択して **Export Selected Meshes** を押します。
2. **移植先のシーン**：**Import and Transfer** を押します。

読み込みは Undo（Ctrl+Z）で戻せません。取り消したいときは、移植したメッシュを削除してください。

### 1. 書き出し（Export from the source scene）

| 項目 | 説明 |
|---|---|
| Save to: Temp folder | Maya の一時フォルダに保存します。書き出すたびに上書きされます。（既定） |
| Save to: Custom folder | 保存するフォルダとファイル名を自分で決めます。ファイルを残したいときや、他の人に渡すときに使います。 |

項目の下に、実際に保存される場所が表示されます。

### 2. 読み込み（Import into the target scene）

| 項目 | 説明 |
|---|---|
| Import from: Last export | 直前に書き出したファイル（1. で設定した場所）を読み込みます。（既定） |
| Import from: Another file | **Browse...** を押して、このツールで書き出した `.ma` ファイルを選びます。任意のフォルダに保存したファイルや、他の人からもらったファイルを読み込むときに使います。 |
| If a material exists: Use existing | 同じ名前のマテリアルがシーンにあれば、読み込んだメッシュもそれを使います。読み込んだマテリアルは捨てます。（既定） |
| If a material exists: Use imported | 読み込んだマテリアルで置き換えます。既存のマテリアルを使っていたメッシュ（古いメッシュも含む）はすべて新しいマテリアルに付け替わり、既存のマテリアルは削除されます。 |
| If a material exists: Keep both | 両方残し、読み込んだ側に New suffix を付けます（例：`skin_mat` と `skin_mat_imp`）。新旧を見比べたいときに使います。 |
| Place meshes under: Matching parent | 元の親と同じ名前のノードがあれば、その下に入れます。無ければワールド直下に置きます。（既定）グループを書き出した場合は、グループの置き場所になります。 |
| Place meshes under: Selected node | **Import and Transfer** を押したときに選択しているノードの下に入れます。ノードを1つだけ選んでください。 |
| Place meshes under: World | ワールド直下に置きます。 |
| If a name exists: Replace existing | 読み込んだ側が元の名前を引き継ぎ、既存の側に Old suffix を付けます（例：`body_old` と `body`）。既存の側は削除されずに残ります。（既定） |
| If a name exists: Keep existing | 既存の側はそのままにして、読み込んだ側に New suffix を付けます（例：`body` と `body_imp`）。 |
| New suffix | **Keep existing** のときに、読み込んだ側に付ける接尾辞です。既定は `_imp` です。 |
| Old suffix | **Replace existing** のときに、既存の側に付ける接尾辞です。既定は `_old` です。 |
| Keep the original bind pose | 既定はオフです。オフのときは、メッシュの形を変えずに、移植先の骨の今の姿勢で付けます。読み込む前に、移植先の骨格をバインドポーズにしておいてください。オンにすると元のバインドポーズをコピーするので、移植先の骨がポーズを取っていても正しく付きますが、移植先の骨の位置が元と違うと、メッシュがそれに合わせて動き、変形します。 |

### 任意のフォルダに保存したファイルを読み込むには

1. **Import into the target scene** の欄で **Another file** を選びます。
2. **Browse...** を押して `.ma` ファイルを選びます。
3. **Import and Transfer** を押します。

## 注意点と制限

- **Keep the original bind pose** がオフのときは、移植先の骨の位置を、書き出したファイルに記録されている骨の位置（元のバインドポーズ）と比べます。違う骨があれば一覧を出し、続けるかどうかを確認します。一覧には、違うチャンネル（移動・回転・スケール）だけについて、チャンネルボックスの値を「元のバインドポーズの値 → 移植先の今の値」の形で並べます（例：`tx 12.500 → 13.500`）。「(joint orient differs)」は、その骨の Joint Orient が元と違うことを示します。移植先がポーズを取っている場合は、取りやめてバインドポーズにしてから、読み込み直してください。
- グループを書き出した場合は、移植先にグループも作り直します。同じ場所に同じ名前のグループが既にあれば、新しく作らずにそのグループの中へ入れます。
- 「Replace existing」でも、骨・骨を含むグループ・ロックされたノード・リファレンスのノードは改名しません。その場合は読み込んだ側を改名し、結果に表示します。
- マテリアルの設定は、名前の設定とは別に選べます。たとえば「メッシュは新しいものにするが、マテリアルは既存のまま」といった組み合わせができます。
- 「Replace existing」のときと、グループを新しく作ったときは、書き出し元のノードの並び順を再現します。FBX に書き出したときのノード順が崩れないようにするためです。
- 「Use imported」で削除するのはマテリアルのノードだけで、つながっていたテクスチャは残ります。不要なノードは **ファイル > シーン サイズの最適化** で削除できます。

- 骨は名前で照合します。同じ名前の骨が複数あるとエラーになります。
- 移植先にだけある骨（追加の揺れ骨など）は、スキンのインフルエンスに追加されません。
- スキンより前のデフォーマ（ブレンドシェイプなど）は、メッシュの形に焼き込まれます。
- 書き出す前に、モデリングのヒストリを削除しておいてください。

## 審査・導入担当の方へ

- ツールは実行中に AI を使いません。AI サービスへの接続もありません。
- ネットワーク通信を一切行いません。シーンのデータを外部に送ることはありません。
- ファイルを書き込む場所は、次のとおりです。
  - 書き出しファイル：Maya の一時フォルダ、または利用者が指定したフォルダ
  - インストール時：`Documents/maya/scripts` へのツールのコピーと、シェルフ「o848」の追加（シェルフは Maya の設定フォルダに保存されます）
  - ツールの設定（保存先など）は、Maya の設定（optionVar）に保存されます
- `Maya.env` や `userSetup.py` は書き換えません。
- ソースコードはすべて公開しています。ツール本体は Python のファイル1つです。

## 更新履歴

- **1.3.0** — 「Keep the original bind pose」を既定でオフに変更。オフのときは読み込む前に、移植先の骨の位置を元のバインドポーズと比べ、違う骨があれば一覧を出して続けるか確認するように。読み込み全体を Undo 1回で戻せるように。
- **1.2.0** — グループを選んで書き出すと、グループも一緒に移植するように。名前が競合したとき、読み込んだ側に名前を引き継ぎ、既存の側を `_old` にする「Replace existing」を追加。マテリアルの扱いを3択（既存に統一／読み込んだものに統一／両方残す）に。書き出し元のノードの並び順を再現。名前が競合していないのに `_imp` が付く不具合を修正。
- **1.1.0** — グループを選ぶと中のスキン付きメッシュをまとめて書き出せるように。置き場所の選択（元の親と同じ名前／選択中のノード／ワールド直下）を追加。「Import from: Another file」で任意のファイルを読み込めるように。UI の英語表記をわかりやすく改善。未保存シーンの確認メッセージを廃止。
- **1.0.0** — 初回リリース
