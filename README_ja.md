# o-848 Skin Mesh Transfer

**part of o-848 Tools** — by OhashiYa

[English version](README.md)

スキン付きメッシュを、別の Maya シーンへ移植するツールです。
両方のシーンで同じ骨を使っていれば、メッシュ・スキンウェイト・マテリアルをワンクリックで移せます。

## マテリアルが増えない

普通に読み込むと、移植先のシーンに既にあるマテリアルまで `skin_mat1` のような複製として持ち込まれます。
このツールは、まず移植先のシーンを調べます。同じ名前のマテリアルがあれば、読み込んだメッシュを**既存のマテリアル**に面単位で割り当て直し、持ち込んだ複製は削除します。

- シーンが散らからない：マテリアルやシェーディンググループが重複しません。
- 移植先で調整済みのマテリアルがそのまま使えます。
- 複数のマテリアルを使うメッシュにも対応しています。面ごとの割り当ても保たれます。

これは既定の動作です。読み込んだマテリアルに接尾辞を付けて残すこともできます。

## 主な機能

- 同じ名前の既存マテリアルに割り当て直します（上記）。
- メッシュ、スキン、骨、マテリアルだけを書き出します。リグのコントローラは含みません。
- 移植先のシーンにある同名の骨にバインドします。
- スキンウェイトを頂点単位で正確にコピーします。
- 移植先に無い骨があれば、処理を止めて骨の名前を一覧で表示します。
- 名前が競合したノードにだけ接尾辞を付けます。
- 移植のあと、読み込んだ一時ノード（骨、元のメッシュ、使わなかったマテリアル）をすべて削除します。

## インストール

### ドラッグ＆ドロップ（おすすめ）

1. [最新のリリース](https://github.com/o-848/skin-mesh-transfer/releases/latest)を開き、**Assets** にある `o848_SkinMeshTransfer_vX.X.X.zip` をダウンロードします。
   - zip は丸ごと必要です。`install.mel` は同じフォルダにあるほかのファイルを使います。
2. ダウンロードしたファイルを解凍します。
3. `install.mel` を Maya のビューポートにドラッグ＆ドロップします。
4. シェルフの **o848** タブにボタンが追加されます。

ツールは `Documents/maya/scripts` にコピーされるので、同じ PC のどのバージョンの Maya でも使えます。
インストーラは `Maya.env` や `userSetup.py` を書き換えません。

### 手動

1. `scripts/o848_skin_mesh_transfer.py` を `Documents/maya/scripts` にコピーします。
2. Maya を再起動し、スクリプトエディタ（Python タブ）で次を実行します。

```python
import o848_skin_mesh_transfer
o848_skin_mesh_transfer.show_ui()
```

## 使い方

1. **元のシーン**：スキン付きメッシュのトランスフォームを選択して **Export Selected Meshes** を押します。
2. **移植先のシーン**：**Import and Transfer** を押します。

読み込みは元に戻せないので、事前にシーンを保存してください。

### File Location（保存先）

| 項目 | 説明 |
|---|---|
| Temp folder (default) | Maya の一時フォルダを使います。毎回上書きされます。 |
| Custom folder | 任意のフォルダとファイル名を指定します。ファイルを残したいときや、他の人に渡すときに使います。 |
| Select Existing File... | 読み込む `.ma` ファイルを選びます。 |

### 読み込みのオプション

| 項目 | 説明 |
|---|---|
| Conflict suffix | 名前が既にあるノードにだけ付ける接尾辞です。既定は `_imp` です。 |
| Same-name material: Use existing | 同名の既存マテリアルを割り当てます。 |
| Same-name material: Keep with suffix | 読み込んだマテリアルに接尾辞を付けて残します。 |
| Match parent by name | 元の親と同じ名前のノードがあれば、その下に入れます。無ければワールド直下に置きます。 |
| Copy bind matrices | 元のバインドポーズをコピーします。移植先の骨がポーズを取っていても正しく付きます。移植先の骨のバインドポーズが違う場合はオフにしてください。 |

## 注意点と制限

- 骨は名前で照合します。同じ名前の骨が複数あるとエラーになります。
- 移植先にだけある骨（追加の揺れ骨など）は、スキンのインフルエンスに追加されません。
- スキンより前のデフォーマ（ブレンドシェイプなど）は、メッシュの形に焼き込まれます。
- 書き出す前に、モデリングのヒストリを削除しておいてください。
